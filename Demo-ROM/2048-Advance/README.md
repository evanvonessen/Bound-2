# 2048 Advance — GBA demo

**2048 Advance v1.3.1**, by **Basil Termini**, is a tile puzzle game for the Game Boy Advance.
This package contains the creator's unmodified `2048.gba` download.

- [Official download and game information](https://basil-termini.itch.io/2048-advance)
- [Creator source repository](https://github.com/Paperdomo101/2048-GBA)
- [Creator README snapshot](CREATOR-README.md)
- [Credits and notices](DEMO-ATTRIBUTION.txt)
- [Download provenance and checksums](SOURCE.json)

Relative source links in the creator README snapshot refer to the upstream repository.

Import [2048.gba](2048.gba) through Bound's **+ → Files** picker, then tap the game in the library.
Use the D-pad to slide tiles and combine matching numbers toward 2048.

The ROM is 262,144 bytes. SHA-256:

`6c6cfe318b1c724a29c5e08516a15e5ace354e32b2a04a08d388cfeb4c65ee58`
